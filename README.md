# Minport (v1.1)

Hand-tracked, voice-driven desktop widgets in Electron with a **Widget Gallery**, **custom URL widgets**, and a **brick game**.

## New
- **Widget Gallery** (☰ Widgets): add/remove widgets. “Remove” only hides them—re-add from the gallery anytime.
- Built-ins: Calendar, Weather, Yahoo News, Brick Game.
- Web embeds (iframe): YouTube, Facebook, Twitter, LinkedIn, Google Search, Robinhood.
- **Custom URL widget**: give it a title + URL and it becomes a card.

> Many sites block embedding via CSP/X-Frame-Options. If blocked, Minport shows an “Open in Browser” button.

## Run

npm i
npm start
